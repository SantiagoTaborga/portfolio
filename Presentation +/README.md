# Presentation
The Presentation is a study of racial profiling in the DMV area. Data from the Virginia and Maryland State Patrols was selected to analyze whether an individual's race affects the likelihood that a traffic stop will lead to a search. The analysis is conducted across different racial groups and spans multiple years.

The presentation file is named `index.html`, and is available to view at https://santiagotaborga.github.io/portfolio/. The replication code is found at the `index.Rmd` file.

All data to reproduce this project is available at the Open Policing Project's website at https://openpolicing.
stanford.edu.
